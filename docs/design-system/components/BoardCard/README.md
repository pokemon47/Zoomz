# BoardCard

A child board as a stack of slabs: the top card (preview mosaic set into a recessed well, display-face title, count, cobalt **Open board**) sits on a `lilac` and a `mint` layer — the levels inside. Hover tilts it and fans the stack; double-click or **Open board** dives in. At `far` only the mosaic and a large title show. Consumer passes preview colours or thumbnails, the count and `onOpen`.
